# TicTacToe

Smol TicTacToe implementation with AI opponents and game replay.

## Files

- `game.py` - Game loop, player interaction, and main entry point
- `utils.py` - Board display, win detection, and AI logic  
- `replay.py` - Game recording and replay system

## Features

- Multiple game modes (PvP, Easy/Medium/Hard AI)
- Automatic game recording
- Replay system for last 5 games

## Usage

```bash
python game.py
```

Choose mode:
1. PvP
2. Easy
3. Medium
4. Hard
5. Replay
